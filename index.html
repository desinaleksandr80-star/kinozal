Меня позвали

  • Лучшее качество. Если фильм скачан у обоих — второй жмёт «У меня есть этот файл». Каждый смотрит свой файл в полном качестве, а зал держит вас синхронно.
  • Если файла нет. Ведущий транслирует фильм сам — до 1080p со стерео-звуком, сколько позволит интернет.
  • Показ экрана. Кнопка «Показать экран» в зале — игра, браузер, что угодно, до 60 к/с. В окне выбора оставь галочку «Поделиться системным звуком».
  • Наушники. Иначе звук фильма попадёт в микрофон и будет эхо.
  • Браузер. Chrome или Edge на компьютере. Файл этой страницы просто перешли брату — пусть откроет его так же.
  • Брату. Перешли ему Kinozal.exe — устанавливать ничего не нужно, просто запустить. Дальше вы встречаетесь по коду зала.

Файл субтитров увидят все. Сдвиг — только у тебя. Субтитры внутри MKV браузер не видит, их можно вытащить: ffmpeg -i "фильм.mkv" -map 0:s:0 subs.srt

Браузер не тянет этот файл

Нет ffmpeg? Поставь одной командой: winget install Gyan.FFmpeg и перезапусти PowerShell. Команду запускай в папке с фильмом: Shift + правый клик по пустому месту → «Открыть в Терминале».
